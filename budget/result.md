# budget 결과: 예상 경비표

## 0. 입력 확인
- 일정: 확인됨 (schedule/result.md 요약, 1박 2일 2026-05-14~05-15)
- 숙소 정보: 확인됨 (100,000원/인/박, 정산 대상 2명, 1박)
- 교통 정보: 확인됨 (항공 100,000원/인/편도, 렌트·택시 100,000원/회)
- → 세 가지 정보가 모두 있으므로 경비 계산 진행

## 1. 계산 근거 (input-sample.md 수치만 사용)

### 교통비
| 세부 항목 | 단가 | 수량 | 금액 |
|---|---|---|---|
| 항공 (왕복 = 편도 2회) | 100,000원/인/편도 | 2명 × 2편도 | 400,000원 |
| 렌트·택시 | 100,000원/회 | 2회 (1일차 1회 + 2일차 1회) | 200,000원 |
| **교통비 소계** | | | **600,000원** |

### 숙박비
| 세부 항목 | 단가 | 수량 | 금액 |
|---|---|---|---|
| 숙박 | 100,000원/인/박 | 2명 × 1박 | 200,000원 |
| **숙박비 소계** | | | **200,000원** |

### 기타 (식사비·다과비, 전체 참석 인원 8명 기준)
| 세부 항목 | 단가 | 수량 | 금액 |
|---|---|---|---|
| 식사비 | 15,000원/인/회 | 8명 × 5회 | 600,000원 |
| 다과비 | 7,500원/인/회 | 8명 × 5회 | 300,000원 |
| **기타 소계** | | | **900,000원** |

## 2. 예상 경비표 (요약)

| 항목 | 금액 | 산출식 |
|---|---|---|
| 교통비 | 600,000원 | (100,000×2×2) + (100,000×2) |
| 숙박비 | 200,000원 | 100,000×2×1 |
| 기타 (식사·다과) | 900,000원 | (15,000×8×5) + (7,500×8×5) |
| **합계** | **1,700,000원** | 600,000 + 200,000 + 900,000 |

## 3. 예산 대비 판정

| 예산 상한 | 총 경비 | 판정 | 이유 |
|---|---|---|---|
| 1,900,000원 | 1,700,000원 | **가능** | 총 경비(1,700,000원)가 예산 상한(1,900,000원) 이내이며, 200,000원 여유가 있음. 초과 항목 없음. |
