## 2. 구조화된 출장 정보

- 기간: 2026-05-14(목) ~ 2026-05-15(금), 1박 2일
- 필수 방문지: 총 6개소 (아래 목적지 목록 참조)

### 2-3. 인원 (총 8명)

### 2-6. 목적지 간 거리·이동시간

좌표를 확인할 수 없어(위 2-5 비고 참조) 실제 거리·이동시간 수치는 산출하지 못함. 이후 GeoCoding·경로 조회가 가능한 도구가 연결되면 아래 구간에 대해 정리가 필요함.

| 구간 | 거리 | 이동시간 | 비고 |
| --- | --- | --- | --- |
| 연번1(대정읍) → 연번2(남원읍) | 확인 불가(외부 조회 도구 없음) | 확인 불가(외부 조회 도구 없음) | 1일차 이동 후보 구간(추정) |
| 연번2(남원읍) → 연번3(성산읍) | 확인 불가(외부 조회 도구 없음) | 확인 불가(외부 조회 도구 없음) | 1일차 이동 후보 구간(추정) |
| 연번3(성산읍) → 연번4(구좌읍) | 확인 불가(외부 조회 도구 없음) | 확인 불가(외부 조회 도구 없음) | 1일차→2일차 이동 후보 구간(추정) |
| 연번4(구좌읍) → 연번5(한림읍) | 확인 불가(외부 조회 도구 없음) | 확인 불가(외부 조회 도구 없음) | 2일차 이동 후보 구간(추정) |
| 연번5(한림읍) → 연번6(제주 미정 1개소) | 확인 불가(외부 조회 도구 없음/주소 미정) | 확인 불가(외부 조회 도구 없음/주소 미정) | 목적지 미확정으로 산정 불가 |

비고: 구간 순서는 원자료의 연번 순서를 그대로 나열한 것일 뿐, 실제 방문 순서(동선)는 이후 동선·일정 단계에서 결정되어야 함. 이 표는 좌표·거리 데이터가 없는 상태를 정리한 것이며 임의로 순서나 수치를 지어내지 않았음.
